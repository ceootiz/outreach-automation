УСТАНОВКА

1. Распакуйте архив в любую папку.

Например:

C:\Gmail-Rassylka

2. Откройте папку:

Gmail Рассылка

3. Запустите:

Gmail Рассылка.exe

Если Windows покажет предупреждение:

* Нажмите "Подробнее"
* Нажмите "Выполнить в любом случае"

Это нормально для тестовой сборки без цифровой подписи.

ДАННЫЕ ПОЛЬЗОВАТЕЛЯ

Программа автоматически создаст свои рабочие папки при первом запуске.

ЧТО ПРОВЕРИТЬ

1. Приложение запускается без .env и без терминала.
2. Раздел "Аккаунты и настройки" открывается, поля Gmail доступны для ввода.
3. Gmail App Password скрыт точками и сохраняется без показа пароля в интерфейсе.
4. После перезапуска Gmail-профиль остается доступным.
5. Тестовый режим и dry-run не отправляют реальные сообщения.
6. Кнопки, таблицы, поиск и переключение разделов работают без зависаний.

Не используйте реальные массовые рассылки в тестовой сборке.

Для технической проверки Codex откройте файл:

CODEX_WINDOWS_HANDOFF_RU.md

УДАЛЕНИЕ

Для удаления просто удалите папку с программой.
